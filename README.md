# DevOps Git Workflow Project

A hands-on Git and GitHub project demonstrating version-control best practices used in DevOps environments.

## Objective

Manage a DevOps project using Git best practices, including:

- Branching
- Meaningful commits
- Pull requests
- Merge workflow
- Git tags
- `.gitignore`
- Markdown documentation
